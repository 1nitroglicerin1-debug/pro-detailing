# PRO-DETAILING — детйлинг-студия в Екатеринбурге

Премиальный многостраничный сайт детейлинг-студии **PRO-DETAILING** (г. Екатеринбург, ул. Щорса, 128).

## Технологии
Чистый HTML5 + CSS + vanilla JS, одна общая тема (`assets/style.css`) и общий скрипт
(`assets/app.js`). Работает оффлайн в браузере, без сборщиков.

## Структура
- `index.html` — главная: презентация студии, витрина услуг, бейдж «Хорошее место 2026», квиз-калькулятор, отзывы
- `okleyka.html` — антигравийная защита кузова (PPF, зоны риска, полный кузов, цветной винил)
- `keramika.html` — полировка, жидкое стекло, нанокерамика
- `himchistka.html` — химчистка интерьера, защита кожи, озонация
- `pdr-stekla.html` — PDR (удаление вмятин без покраски), ремонт и замена автостёкол
- `kontakty.html` — адрес, телефоны, режим работы, карта и форма записи
- `assets/logo.png` — оригинальный логотип, вырезанный из референса
- `assets/style.css` / `assets/app.js` — общая тема и логика (квиз, форма, меню, анимации)
